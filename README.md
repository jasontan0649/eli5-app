# Explain Like I'm 5

An AI-powered web app that turns difficult concepts into simple and easy-to-understand explanations.

Built with Next.js, Tailwind CSS, and Groq API.

---

## Features

- AI-generated simplified explanations
- Easy analogy generation
- Mobile-friendly responsive UI
- Bright mode and dark mode support
- Multiple explanation tones
- Audience level selection
- Fast inference powered by Groq
- Clean modern interface

---

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Groq API
- Vercel

---

## Installation

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/eli5-app.git
```

Go into the project folder:

```bash
cd eli5-app
```

Install dependencies:

```bash
npm install
```

---

## Environment Variables

Create a `.env.local` file in the root directory:

```env
GROQ_API_KEY=your_groq_api_key_here
```

---

## Deployment

This project is optimized for deployment on Vercel.

Deploy instantly:

- Push project to GitHub
- Import repository into Vercel
- Add environment variable
- Deploy
